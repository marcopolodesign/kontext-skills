# Kontext skills

Agent skills from Kontext, the design agent by Marco Polo.

```bash
npx skills@latest add marcopolodesign/kontext-skills
```

| Skill | What it does |
|---|---|
| `kontext-review` | Strict design review: blocks the patterns that make a site look AI-made, gives every fix as Before / After / Why, ends with Approve or Block. |

Full analysis of your site against your own brand: https://kontext.marcopolo.agency/?utm_source=skill&utm_campaign=readme
